# Images du site

## Photo du hero (page d'accueil)

Dépose ici un fichier **`hero.jpg`** : il s'affichera automatiquement en fond de la
section d'accueil (et de la bannière d'appel à l'action), avec un fondu doux.

- Format conseillé : JPG, ~2000×1200 px, < 500 Ko
- Si le fichier est absent, le site affiche simplement le décor CSS (dégradé olive +
  halos lumineux) — rien ne casse, aucune étape obligatoire.

Exemple de commande depuis la racine du projet :

```bash
cp ~/Downloads/ma-photo-cuisine.jpg public/hero.jpg
```
